# 情绪胶囊机 · Emotion Capsule Machine

**把屁话装进胶囊，把坏情绪砸成惊喜。**
## 为什么做这件事

我们每天被迫听很多屁话，但碍于礼仪和权力没法回怼，只能憋着。憋着憋着，就内耗了。

市面上不缺解压产品：电子木鱼、捏捏乐、尖叫鸡……它们都很好，但都是**一次性消耗**——捏完就完，敲完就完，没有闭环。

我们想做的是：**收集 → 兑换 → 砸碎 → 惊喜** 的完整情绪游戏。让"憋着"变成可积累、可释放、可回味的日常仪式。

**在线体验**：https://emotion-capsule.app.workbuddy.host/

## 它能干什么

| 功能 | 说明 |
|---|---|
| 🎤 语音录入 | 按住「有屁快放」说话，说完停顿自动发射 
| 🧪 AI 分类 | 分为废话型 / 画饼型 / 甩锅型 / 黑话型 / 癫言癫语，输出离谱度评分 + 毒舌人话翻译。
| 🗑️ 入桶 | 胶囊掉进对应类别的桶里，带易拉罐落桶音效 
| 🥚 兑换扭蛋 | 集齐 5 颗换普通蛋，单类集 3 颗换专属蛋，五类全满解锁彩虹蛋 
| 💥 砸蛋 | 长按举起 → 松手砸烂，随机开出三种惊喜 
| 🤐 关你屁事 | 把你听到的话改成一句体面的回怼，三种语气任选
| 🤐 屁话连篇 | 积攒情绪碎片，生成屁话周报
