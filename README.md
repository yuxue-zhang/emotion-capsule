# 情绪胶囊机 · Emotion Capsule Machine

把职场屁话装进胶囊，再砸开它。

一台单文件的网页扭蛋机：对着它说出那句让你憋屈的职场话 → 转文字 → AI 归类成五种「口气污染」 → 塞进胶囊 → 攒够 5 颗换一枚扭蛋 → 举高、松手、砸烂 → 开出放屁 / 泼墨 / 今日签语。

**在线体验**：https://emotion-capsule.app.workbuddy.host/

---

## 它能干什么

| 环节 | 说明 |
|---|---|
| 🎤 憋气录音 | 按住「有屁快放」说话，说完停顿自动发射；音量实时驱动气压计 |
| 🔤 语音转文字 | MediaRecorder 录音 → 云端 ASR。麦克风权限被拒 / 非 HTTPS / 被占用会分别给不同指引 |
| 🧪 AI 分类 | 分为废话型 / 画饼型 / 甩锅型 / 黑话型 / 癫言癫语，输出离谱度评分 + 毒舌人话翻译。AI 不可用时自动退回本地关键词规则 |
| 🗑️ 入桶 | 胶囊掉进对应类别的桶里，带易拉罐落桶音效 |
| 🥚 兑换扭蛋 | 集齐 5 颗换普通蛋，单类集 3 颗换专属蛋，五类全满解锁彩虹蛋 |
| 💥 砸蛋 | 长按举起 → 松手砸烂，随机开出三种惊喜 |
| 🤐 关你屁事 | 把你听到的话改成一句体面的回怼，三种语气任选 |

## 技术要点

- **单文件**：整个应用就是一份 HTML（内联 CSS / JS / base64 音频），离线也能跑
- **录音方案**：`MediaRecorder` + `getUserMedia`，不用 Web Speech API（国内 Android / iOS 基本不可用）
  - `getUserMedia` 必须在用户手势的同步调用栈里发起，否则 iOS 会静默拒绝
  - iOS 音频解锁、Blob 体积判空、静音检测都有专门处理
- **ASR 模型**：主用 `Qwen/Qwen3-ASR-1.7B`（实测 0.3s），超时或失败时回退 `FunAudioLLM/SenseVoiceSmall`
  - 有 8 秒超时，不会让用户干等
- **数据**：全部存在浏览器本地（IndexedDB，失败时降级 localStorage），不上传、无账号
- **音效**：Web Audio 实时合成，屁声用真实录制的 mp3 内联成 base64

## 本地运行

直接用浏览器打开 `index.html` 即可。

⚠️ 麦克风要求**安全上下文**：`https://` 或 `localhost` 才可用。直接双击打开本地文件（`file://`）浏览器会禁用麦克风——这是浏览器规则，不是 bug。

需要改代码的话，改 `情绪胶囊机_原型.html`（源文件），然后：

```bash
node 生成分享版.js --public   # 生成对外版本，同步到 gh-pages/index.html
```

不要直接编辑 `gh-pages/index.html`，它是生成产物。

## 部署

```bash
# GitHub Pages
GITHUB_TOKEN=<your_token> node 部署Pages.js "提交说明"

# WorkBuddy 托管
# 发布目录：gh-pages，入口：index.html
```

## 关于密钥

对外版本内置了语音识别 API Key，并做了 Base64 混淆。**前端页面无法真正隐藏密钥**，任何人查看源码都能提取。

如果要长期对外分享，建议单独申请一个低额度专用 Key，随时可作废。
